# 选题连续浏览和本地标记

- 单列内容流，滚动追加和手动加载更多；正文可展开，图片和视频可横向浏览。
- 已读、未读、收藏、隐藏已读使用用户与租户隔离的浏览器存储；成功打开选题后才标记已读。
- 快捷时间和排序常驻筛选区域，高级条件可收起；翻译及缩写仍仅由运营手动触发。
- 本地标记随查询上传 ID 条件，只用于后台只读过滤，不保存到数据库。
- 本地存储损坏回退为空，空间不足提示；跨浏览器和设备不共享，清除浏览器数据会丢失。
- 筛选条件按请求快照分页，旧请求不能覆盖新结果，加载失败保留已有帖子。后台采用现有 offset 分页，实时排名变化时可能移动帖子，前端按 ID 去重。
- 验证：前端 870 项测试、类型检查和构建；后端 89 项及 42 子测试、隔离 PostgreSQL 11 项。
- 不包含主题分类、自动翻译、按目标账号发布情况筛选，不部署生产。
