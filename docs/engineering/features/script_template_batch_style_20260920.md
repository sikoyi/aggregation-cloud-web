# 脚本与任务模板批量操作栏统一

- 用户要求：脚本管理、任务模板与账号数据等页面的批量操作样式全部统一。
- 实现：复用 CrudPage 常驻工具栏，不另建组件；无选中项时展示并禁用按钮，选中数量使用“个脚本”和“个模板”。沿用 52px 最小高度、主题色、默认尺寸按钮、移动端换行和表格衔接样式，不展示取消选择按钮。
- 边界：保留原有权限、动作、确认弹窗和请求逻辑；不修改服务端或执行脚本，不部署生产。
- 验收：组件测试、构建，浏览器检查空选、勾选、取消勾选、只读权限、桌面/窄屏及浅色/暗色展示。
- 结果：96 项组件与资源配置测试通过；类型检查及生产构建通过；`smoke-script-template-batch-style.cjs` 浏览器回归通过，接口完全模拟、无真实写操作。本地热更新验收，未发布。
