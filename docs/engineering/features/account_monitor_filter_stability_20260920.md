# 账号状态筛选布局稳定

- 场景：点击账号总数、监听中、已关闭、监听异常、未开启卡片切换列表时页面抖动。
- 确定问题：筛选标题从无标签的 19.5px 变为有标签的 20px，下方筛选项和列表整体移动 0.5px；20 条结果与 0/1 条结果使页面跨越纵向溢出阈值，经典滚动条会改变可用宽度。
- 修复：标题最小高度 20px；文档根元素使用 `scrollbar-gutter: stable`，仅预留页面滚动条位置，不改变列表行数、卡片选择逻辑或接口，不强制空列表占用整页高度。
- 验收：Playwright 比较筛选前后标题、筛选项坐标及容器尺寸；模拟 20/0/1/7 条结果并校验布局与 gutter；保留桌面、平板、窄屏、浅色和暗色截图。原有组件测试、类型检查、生产构建应通过。
- 范围：仅前端，本轮不部署生产。
- 结果：45 项单元测试、类型检查和生产构建通过；状态卡片布局回归及外部监听批量操作浏览器回归均通过。本地 Vite 热更新验证，未改动后台服务。
