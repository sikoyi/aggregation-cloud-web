# 监听弹窗嵌套滚动修复

## 范围与根因

- 账号树已有内部虚拟滚动，但选择器外框仍被限制为 420px 并开启 overflow:auto。
- 实测外框 clientHeight=418、scrollHeight=451，产生多余外层滚动条。
