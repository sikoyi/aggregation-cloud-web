# 对标监听历史错误展示

## 范围

只调整账号数据的监听设置弹窗，区分状态读取失败、当前采集失败及历史采集失败；不调整采集频率、来源门槛、下发参数或脚本，不自动保存或重试任务。

## 行为

- 已关闭、正在重试、后续已成功或输入已更换来源时，旧错误显示为信息态的“历史采集失败”，保留错误内容。
- 历史错误明确显示北京时间、保存规则的来源及采集记录号；缺时间显示未记录，不伪造时间，也不归到输入的新来源。
- 当前来源当前批次的失败仍为错误态；读取状态接口失败独立显示“读取对标状态失败”。
- Threads .net/.com、X/Twitter 别名、大小写、尾部斜线及查询参数不造成假换源；复用现有敏感错误脱敏工具。
- 复用现有 Element Plus alert、主题变量和移动端弹窗样式，长错误与上下文换行，不覆盖保存操作或编辑值。

## 验证

既有前端 128 个文件、1023 条测试，类型检查及生产构建通过；未新增或修改测试文件。临时本地验证 27 项含提示分类、别名、时间/来源/记录号、错误脱敏、桌面及 390px 暗色截图、无溢出和无业务写请求。只保留本地代码提交，未推送或发版。
