# 发布内容池数量按使用状态展示

## 范围

- 仅调整发布配置中内容池下拉选项的数量：未使用显示 `unused_count`，已使用显示 `member_count - unused_count`，全部显示 `member_count`。
- 使用已有分组统计，随表单上下文重新渲染，不因切换使用状态新增网络请求，不清空已选择内容池。
- 为远程选项格式化回调增加可选的表单上下文参数；原有单参数格式化函数继续兼容，其他内容池选择器保持原展示口径。
- 有效的 0 显示为 `0`；缺失、空白、负数、非整数、非有限数和不安全整数等异常统计显示 `--`。已使用数依赖两项有效统计，未使用数大于总数时不展示负数。
- 未提供使用状态时维持未使用口径；明确的 `all` 或 `null` 对应全部，未识别的使用状态显示 `--`，不修改原有表单提交或校验行为。

## 非目标

- 不修改请求体、后端筛选、随机分配、批内不重复及内容不足拦截规则。
- 不修改任务脚本、内容使用状态、生产配置或已有任务，不自动下发或重跑任务。
- 不新增或修改测试代码，不推送、不发版。

## 验证计划

- 复核生产现象对应的总数 4、未使用 0：未使用 0、已使用 4、全部 4。
- 验证空池、混合状态、数值字符串、统计缺失和非法统计。
- 验证快速切换上下文、已选内容池不丢失，以及单参数格式化函数兼容性。
- 对比修改前后的发布请求体；运行既有前端测试、类型检查与构建，并在本地界面只读核对，不实际发布内容。

## 验证结果

- 全量既有前端测试：128 个文件、1,022 项通过；未新增或修改测试源码。
- 类型检查和生产构建通过；仅有依赖中的 PURE 注释警告。
- 直接加载实际发布配置及 `RemoteSelect` 格式化函数，21 个统计/状态边界通过；实际 Vue 响应式上下文连续切换 300 次，显示及时更新且已选池 ID 不变；原有单参数格式化函数兼容。
- 总数 4、未使用 0 的场景显示：未使用 `0`、已使用 `4`、全部 `4`。空池、混合状态、数字字符串、统计缺失、非法数值和无效状态均按约定展示。
- 通过 TypeScript AST 打印规范化后比对，发布请求构建函数与修改前一致；后端与任务执行代码未改动。
- 本地保持原后台环境与数据，仅查看发布弹窗和切换状态；原库无现成内容池，因此浏览器验证空池提示，4 条内容与已选项保留通过实际组件内存场景验证，未为验证向原库添加内容。
