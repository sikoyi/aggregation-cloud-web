# 社媒账号设备分组列展示设备 ID

## 确认范围

用户确认在社媒账号数据的设备分组列中，上方保留分组名称，下方增加对应设备 ID。ID 使用后台 bound_slot_provider_id，与设备管理 provider_slot_id 口径一致，不显示内部设备记录编号。

## 展示

- 复用原分组标签与 tooltip；下方使用可选中的等宽 ID，长值省略，悬停标题保留完整内容。
- 未分组但有设备的账号继续显示真实 ID；没有设备显示未绑定设备；旧接口有设备名但没有 ID 时显示设备 ID 未记录，不误称未绑定。
- 身份聚合父行继续显示占位，展开后的各平台叶子显示各自设备，不混用另一平台或旧会话设备。
- 仅适度加宽这一列，不改其他列、排序、筛选、分组、绑定或执行端，不增加逐账号接口请求。
