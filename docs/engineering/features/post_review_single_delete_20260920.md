# 帖子审核单条删除

- 操作列在查看、失败重试旁保留单条删除图标和提示，不取代批量删除。
- 仅具有 operations.review 权限的用户可以删除成功、失败、忽略、取消、超时或结果丢失等终态记录；待审核及执行中的工单不显示删除入口。
- 复用已有软删除接口，仅提交当前工单 ID，保留发布任务、帖子映射和审计；确认前不请求，处理中防重复，后端状态变化时明确提示未删除。
- 成功后刷新列表、清空旧选择、关闭相同工单详情；删除尾页最后一项时返回上一页。
- 不改变服务端，不涉及真实删除或生产发版；筛选项扩展属于此前待确认方案，本轮不混入。
- 验收：10 项组件/接口测试、类型检查及构建通过；模拟浏览器验证取消无请求、非终态不显示删除、后端跳过时提示未删除、成功后列表刷新，三个操作图标无重叠。本地热更新，未发布。
