# 监听开关与采集结果分开展示

## 范围

账号数据总览、身份下各平台账号、侧栏及账号详情复用 AccountMonitorStatus，分别展示规则开关与最近采集结果。已开启不代表已采集成功；异常自动停用仍独立表示。

## 展示规则

- 规则标签使用监听已开启、监听已关闭、异常已停用、未配置监听。最近结果显示最近采集失败、最近采集成功或尚未采集成功，不改原筛选参数及计数口径。
- 当前错误或晚于成功的失败时间仍表示未恢复，保存/关闭/开启不在页面上伪造成功。只有较新的真实成功结果才去掉当前失败提示，旧失败事实由后端历史保留。
- 详情错误包含发生时间及具体原因；错误详情统一北京时间，缺日期明确未记录。继续复用错误脱敏，不把未知时间当当前时间。
- 侧栏按钮内只使用不可点击标签，避免嵌套按钮；总览与详情的失败标签可打开原因和发生时间。身份聚合按各平台分别展示，避免一个成功账号掩盖另一个失败账号。

## 验证

既有前端 128 个文件、1023 条测试及类型检查/构建通过，未改前端测试文件。临时浏览器验证 49 项（含既有对标历史错误提示兼容检查）覆盖失败/成功切换、日期/原因、桌面与 390px 暗色和美国时区，无浏览器异常、业务写请求、嵌套按钮或横向溢出。
