# 注册资源批量删除

- 用户确认在资源批次列表增加批量删除；不增加资源模板或明文资料批量删除。
- 常驻操作栏与其他资源列表保持一致，未选择或处理时禁用；仅具有 `registration_resources.delete` 权限的用户可勾选和删除。
- 一次确认后逐批次调用已有删除接口，保留服务端租户、权限、预留及已使用资源保护。部分失败继续执行，结果弹窗展示成功/失败数量、批次名称和失败原因；不自动重试删除。
- 刷新、翻页、切换标签清空选择；批量确认与执行期间防止重复提交，列表回到第一页避免删空尾页。
- 验收覆盖空选、取消、权限、重复提交、部分失败、重新加载、浅色/暗色及窄屏。不改服务端和脚本，不部署生产。
- 结果：11 项组件/接口测试、类型检查、生产构建通过；批量删除及既有注册资源隐私浏览器回归通过。全部使用模拟接口，本地热更新验收。
