# 任务执行结果状态样式

## 范围

- 任务详情中的执行结果提示由任务最终状态决定，不再固定显示成功样式。
- `all_failed`、`failed`、`expired`、`lost` 使用失败样式。
- `canceled` 使用中性样式，`succeeded`、`completed` 使用成功样式，其他未结束或未知状态使用警告样式。
- 仅调整前端展示，不修改任务状态、结果正文、后端接口、历史数据或执行端脚本。

## 验收

- 失败任务即使返回了非空结果正文，也必须显示红色失败提示图标和背景。
- 成功、取消及未结束任务继续使用与状态相符的提示样式。
- 单元测试覆盖全部已知任务终态、未结束状态以及详情组件的动态绑定。

## 回滚

- 撤销本次前端提交即可，不涉及数据库迁移或数据恢复。
