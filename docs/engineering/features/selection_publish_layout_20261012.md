# 选题发布窗口布局

## 范围
- 发布账号独立置顶，选择器显示头像（缺失时使用占位图标）、昵称、用户名、平台及 ID。
- 原文与发布稿桌面左右对照，窄屏上下排列，正文区域对齐。
- 手动 AI 工具集中到发布稿标题栏，生成预览和确认应用保持原逻辑。
- 仅有媒体时显示媒体选择区；发布历史默认折叠，无历史仅显示一行状态。
- 弹窗垂直居中，内容超高时仅正文区域滚动，头部与底部操作保持可见。

## 不变项
不改接口、权限、发布和重试规则、AI 请求与结果应用逻辑，不发布生产。

## 验证
- 类型检查与构建通过；前端 861 项单元测试通过。
- Playwright 1440px / 390px 模拟账号及 AI 响应：手动触发、预览不改正文、确认应用、保留原帖、不触发发布均通过。
- 浏览器截图核对标题工具栏、左右对照和窄屏排列；未使用真实账号发帖或调用真实 AI。
