# 帖子审核菜单待审核数量

- 范围：仅左侧“帖子审核”菜单增加红色数字角标，0 隐藏，超过 99 显示 99+；不修改菜单跳转、页面筛选、审核流程或执行端。
- 数据：复用审核列表接口，限定 pending_review、第一页一条，读取 total；沿用服务端租户、平台和账号权限，不受页面临时筛选影响。
- 更新：登录/权限就绪时加载，审核列表主动刷新后更新；可见页面每 30 秒同步，后台标签页暂停，返回时刷新。
- 边界：同一会话串行请求并合并刷新；切换账号、退出、失去权限和卸载时清理计时器及请求，旧响应不能覆盖新会话；失败不弹窗、不清空已知数量，后续刷新重试。
- 验证：计数、权限、切换账号、请求竞争、失败恢复、隐藏页面和卸载测试；类型检查、构建、菜单视觉检查。
- 交付：仅本地前端提交和验证，不推送、不发生产，无数据库迁移。

- `npm test`：112 个测试文件、886 项测试全部通过，包含新增计数及接口契约测试。
- `npm run build`：Vue/TypeScript 类型检查与 Vite 生产构建通过；依赖的 PURE 注释警告不影响构建。
- Playwright 使用隔离浏览器上下文和模拟接口检查 1440px 桌面与 390px 窄屏：菜单显示 99+、刷新为 7、归零隐藏、角标不覆盖文字，未发生页面运行异常；没有写入真实工单。
