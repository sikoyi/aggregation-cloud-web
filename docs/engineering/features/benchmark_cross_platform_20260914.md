# Threads / X 跨平台对标设置

## 范围

- 保留“业务 App”作为目标平台；新增“对标来源平台”，两者独立选择 Threads 或 X。
- 来源 URL 提示随来源平台变化，切换来源清空旧 URL，避免提交错平台链接。
- 保存后窗口保持打开，可以切换目标账号连续设置；不是将同一来源批量绑定给全部账号。
- Threads 目标保留昵称、简介、头像独立选择；X 目标禁用资料同步，并明确说明自动删帖尚未适配。
- 同步记录和对标详情展示来源平台、目标平台，账号数据读取保存的来源平台。

## 验证

- AccountDataMonitor、AccountDataView 两组测试共 16 项通过，覆盖四种来源/目标参数与持续保存。
- `npm run build` 通过。
- Chrome 本地页面检查目标和来源独立选择、X 资料选项禁用、900x700 下对话框边界和截图；无控制台错误，未保存真实跟踪规则。
