# 外部账号监听入口

## 范围

账号数据增加“外部账号监听”视图，独立于自有账号及 Shopify 监听。当前支持 Threads/X 公共主页采集，不涉及账号密码、绑定设备、自动回复或对标发布。

支持平台/状态/关键词筛选、统一分页、连续添加、间隔/备注编辑、暂停/恢复、资料与帖子及最近采集记录查看。操作受 `operations.edit` 控制，平台选项遵循现有数据范围。后端校验是最终权限边界。

## 验证

- 相关前端测试 22 项通过；包含 6 项外部监听实际处理函数测试。构建及类型检查通过。
- 隔离 UI 运行工具：`node tests/ui/external-account-monitor-preview.mjs`，仅监听 127.0.0.1:5198，不转发真实后端。使用合成数据验证连续添加、启停、详情及只读模式（`?readonly`）。测试完成后关闭服务。
- Chrome 桌面与 390x844 表单边界检查通过；长正文有独立滚动，表格在小屏横向滚动，固定列不重叠。
- 本地 5173 前端可以看到入口，但旧业务后端尚无新 API，当前列表会显示 404；这不是接口联调已通过的证据。实际生效依赖主服务及 Worker 更新、迁移 0157。
