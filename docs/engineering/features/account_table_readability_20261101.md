- 平台名称、监听/采集汇总及平台叶子状态由 12px 放大至 14px，标签与可点击异常入口统一 28px 高；汇总行标题和辅助时间也用 14px。
- 中性状态文字改用主题常规文字色，开启/成功/失败使用兼容明暗主题的较深语义色，保留状态含义。
- 平台列调整为 200px，监听采集列为 260px，配合标签间距和行高，避免放大后挤压或裁切。
- 从账号总览移除“帖子总浏览量”“总点赞”两列及对应排序入口；旧本地缓存若仍按这两项排序，回退到默认最新添加排序，保留其他筛选。

- 原本地 admin 后台连接不变，不操作生产，不重跑任务，不推送发版。
- 已获准仅更新相关旧测试断言，不新增测试文件或场景。
