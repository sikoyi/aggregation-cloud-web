# 账号监听间隔按整小时展示

## 范围

- 外部账号列表间隔、外部账号详情监听间隔、内部账号详情监听间隔使用同一展示函数。
- 正整数分钟可整除 60 时换算成小时：60 显示 `1 小时`，120 显示 `2 小时`，360 显示 `6 小时`，720 显示 `12 小时`，1440 显示 `24 小时`。
- 不满整小时或无法整除时保持分钟，不向下取整：59 显示 `59 分钟`，61 显示 `61 分钟`，119 显示 `119 分钟`。
- 兼容合法的数值字符串；空值、空白、非法数值、非正数、非整数及不安全整数显示 `-`。外部形象汇总行维持原有的 `--` 占位。

## 非目标

- 不改变分钟输入框、默认值、表单参数、API、数据库数值、实际监听频率或任务下发逻辑。
- 不新增或修改测试源码，不修改或重跑生产任务，不发布生产。

## 验证计划

- 执行既有前端测试、类型检查与构建。
- 使用实际格式化函数核对整小时、零头分钟、0、缺失及非法值。
- 对照原版本确认组件脚本除导入外不变，保存参数仍为分钟；在本地已有账号数据上只读核对列表与详情。
