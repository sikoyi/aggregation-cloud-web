# 暗黑模式切换

## 范围和交互

- 后台顶部及登录页提供太阳/月亮图标按钮，包含操作提示与可访问名称。
- 默认浅色；手动切换立即生效并保存到本浏览器。刷新、退出登录后仍保留选择，同源标签页同步切换。
- 浏览器禁止本地存储时，当前页面仍可切换；此时无法保证刷新后保留选择。
- 主题选择不需要业务权限，不改后端数据或执行端。

## 实现约定

- 使用 Element Plus 自带暗色变量，根节点 `html.dark` 控制主题。
- `src/theme.css` 定义中性深灰背景、文字和语义状态配色。原有业务样式通过 `var(--app-..., 原色)` 保留浅色外观。
- 不反色图片、视频或素材内容；成功、失败、警告等继续保留对应颜色语义。
- 页面加载前读取主题偏好，避免应用挂载后再跳变；组合式函数统一切换与跨标签页同步。

## 验证范围

- 单元测试覆盖双向切换、保存恢复、非法偏好、禁止存储及跨标签页事件。
- 执行现有前端测试、类型检查和生产构建。
- `scripts/fixtures/theme-preview.html` 提供隔离的真实组件组合，检查导航、设备表格、表单、状态标签、弹窗和评论；不登录账号或写入业务 API，不纳入生产入口。
- 浏览器已检查深浅切换、刷新保留、桌面和 390px 窄屏布局、实际工作台与账号数据页；控制台未发现错误。
- 当前浏览器已有登录状态，访问登录页自动跳转，未退出用户账号。登录入口复用同一切换组件，已通过类型检查和构建，未单独进行登录页视觉验证。
- 验证结果：67 个测试文件、536 项测试通过，生产构建通过。
