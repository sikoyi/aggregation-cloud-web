# 选题筛选横向滚动条去箭头

## 范围

只去除选题池国家、账号标签筛选栏原生滚动条两端的箭头，保留滚动条拖动、横向滚动、键盘焦点、勾选和展开/收起。其他页面、全局滚动条、筛选规则及后台不动。

## 原因与处理

Chromium 中非 auto 的 scrollbar-width/scrollbar-color 优先于旧 WebKit 滚动条样式，Windows 的原生箭头因此仍会显示。仅在共享 SelectionOptionFilter 滚动区域、支持 WebKit 滚动条的浏览器中将这两项恢复 auto，使既有自定义轨道/滑块及按钮隐藏规则生效，并明确隐藏该区域的滚动条按钮；其他浏览器继续使用原 thin 回退。

不删除展开全部按钮的图标，不隐藏整个滚动条，不修改现有测试或新增测试文件，不推送或发版。

## 验证

- 既有前端 128 个文件、1023 条测试，类型检查及生产构建通过。
- 本地 Chromium 临时界面检查 44 项通过，覆盖桌面、390px 窄屏和暗色：按钮显示为 none 且尺寸为零，滑块样式保留；横向溢出、键盘滚动、实际滑块拖动、勾选、展开/收起和筛选请求保持正常，无浏览器异常或业务写请求。
- 仅修改共享筛选组件的四行局部样式和本文档，不混入此前监听状态修复，不改后端、脚本或发布流程。
