# 外部账号常用国家筛选修复

## 范围与决策
- 筛选国家取当前团队常用国家与当前用户可见账号已使用国家的去重并集，常用国家在前。
- 常用国家无需被账号使用即可筛选，零结果保持选中，不回退全部。
- 常用国家新增或移除后沿用 changed 事件刷新。历史账号仍使用的国家继续展示。
- 仅调整外部账号前端；内部账号、采集、发布、脚本、数据库和权限不变。
- 沿用现有只读接口及请求序号保护，不引入接口或依赖。

## 验收与失败行为
- 覆盖未使用国家、新增刷新、删除后的历史保留及无历史移除、重复去重、空列表。
- 请求失败保留现有筛选和数据；较旧响应不能覆盖较新结果。
- 常用国家筛选同时传入列表与汇总；管理事件刷新不提交其他筛选草稿。
- 回归测试：src/components/ExternalAccountMonitors.test.ts。
- 发布仅基于 v2026.10.16.2 加入本修复，不包含其他开发分支功能。

## 后续调整：多选与样式统一
- 国家筛选复用 ExternalAccountTagSelect，与账号标签相同边框、勾选与间距。
- 多个国家按任一匹配，未设置国家保持互斥；账号编辑国家仍为单值。
- 列表和汇总均发送 countries 数组（查询序列化为逗号分隔），清空代表全部。
- 查询条件复制数组，刷新仅移除失效项，保留其他有效国家及尚未提交的筛选草稿。
