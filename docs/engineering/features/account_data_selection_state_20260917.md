# 账号数据视图切换选择状态

## 范围

- 账号总览的勾选仅在当前总览视图内有效。
- 从账号总览切换到账号详情时，同时清空表格复选框和批量操作状态。
- 返回账号总览后保持未选中状态，不恢复离开前的选择。
- 不修改分页、筛选、账号详情、批量设置接口或后端数据。

## 验收与失败行为

- 选中当前页账号后，批量操作栏正常出现。
- 切换到账号详情再返回总览，复选框保持未选中，批量操作栏不再显示。
- 无论从账号行进入详情，还是使用顶部视图切换，都执行同一清理逻辑。
- 清理表格实例失败时，内存中的已选账号仍必须清空，避免误操作隐藏选择。

## 决策

- 选择状态属于总览页临时交互状态，不跨视图持久化。
- 复用 `clearOverviewSelection()`，不增加新的选择状态来源。
