# 云手机上号预选请求循环修复

## 边界

- 修复重新上号及共用动态表单的云手机分组预选；不改后端、执行端、代理规则或设备分配接口。
- 业务条件不变时，表单回写不得重复预选。保留手动选择，忽略过期和卸载后的响应。
- RemoteSelect 按选中值内容监听；相同在途加载复用，不缓存已完成请求，不跨分组复用失效请求。
- 用户本轮授权修复与验证，未发布生产。

## 原因与实现

- 原 watch 的单一 getter 每次返回新数组，预选响应替换 modelValue 后会再次触发自身。
- 改为多源 watch，批量上下文按内容比较；相同设备结果不回写。
- 设备选择器增加当前请求复用与卸载序号失效，保留已有请求序号隔离。

## 验证

- 专项测试覆盖一次变更一次请求、无关编辑、手动选择、乱序响应、清空分组、切换平台、关闭、失败、单账号与批量平台过滤，以及设备加载复用、失败重试和 A-B-A 切换。
- 前端全量测试、类型检查及生产构建；本地开发服务健康检查。
- 不在生产提交上号操作或执行设备分配。
