- 在粉丝与距上次发帖之间增加居中的“帖子总数”，使用已有接口的 `posts_count` 平台帖子数，不新建查询、汇总或采集任务。
- 沿用现有数字字号和简写组件：未知/无效为 `--`，零为 `0`，千位简写可点击查看完整数值。
- 多平台合并行不借用首个平台或跨平台求和，显示 `--`；展开后分别显示各平台的帖子总数。
- 仅增加只读列，不提供原后台尚不支持的帖子数排序，保留现有粉丝与发帖时间排序；不恢复已移除的总浏览量/总点赞列。
- 原本地接口的 OpenAPI 已确认包含该字段，不需要后端更新或数据库迁移；本地 admin 连接、原数据、生产和脚本均不变。
- 不新增或修改测试代码，使用既有回归、构建和临时浏览器验证数值边界、合并/展开和桌面/深色/窄屏。
