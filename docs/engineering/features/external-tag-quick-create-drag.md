# 外部账号标签快捷新增与拖拽

- 仅外部账号：添加/编辑弹窗标签区新增加号入口，新标签追加末尾并勾选；不清空账号表单。
- 标签选择区拖动手柄调整共享标签顺序；管理标签、常用国家支持拖动到整行，并保留上下按钮作为键盘替代。
- 复用带版本校验的既有排序接口；保存失败不乐观提交排序，刷新服务端数据，不覆盖其他运营的变更。
- 不接受跨区域拖拽、过期列表或无效下标；保存期间禁用重复操作；不修改内部标签、后端和执行端脚本。
- 不新增测试代码，不下发任务、不部署生产。
- 验证：类型检查与生产构建通过，4 个现有测试文件共 65 项通过。临时浏览器验证使用隔离的模拟接口，确认快捷新增、自动勾选、表单保留、标签拖动及两类管理列表整行拖放；检查 1440px 和 390px 截图，未调用生产接口。
